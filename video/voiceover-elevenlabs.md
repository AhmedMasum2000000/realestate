# Second Home Thailand · "The Door Opens" · voiceover script for ElevenLabs

## Voice and settings

- **Voice:** mature, warm and unhurried. Late 40s to 60s. British or neutral international English. Think private bank or five-star hotel, never "advert". Good library starting points: *George*, *Daniel*, *Alice* or *Charlotte*. A cloned or designed voice works if it matches that description.
- **Model:**
  - **Eleven v3** if you want the audio tags below.
  - **Eleven Multilingual v2** if you prefer steadier reads; in that case remove the `[tags]` and keep the `<break>` tags.
- **Settings (v2):**
  - Stability 50%
  - Similarity 75%
  - Style 15–25%
  - Speaker boost on
  - Speed 0.95
- **Settings (v3):** Stability set to "Natural".
- **Pronunciation:**
  - **Khun Boon** = "KOON BOON" (both rhyme with *moon*).
  - **DTV** = "D-T-V".
  - **LTR** is written out as *Long-Term Resident*.
- **Delivery:** generate each line as its own clip. Each clip has a timecode and a time budget, so it can be placed exactly on the film's beats.
